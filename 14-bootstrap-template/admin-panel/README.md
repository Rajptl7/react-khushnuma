# Spark Admin — React + Vite

## Run locally
```bash
npm install
npm run dev
```

## Included pages
- Dashboard: `/`
- Basic Tables: `/tables-basic.html`
- Forms & Input: `/ui-forms.html`
- Buttons & Alerts: `/ui-buttons.html`
- Blank Page: `/page-blank.html`
- Login Screen: `/page-login.html`
- 404 Page: `/page-404.html`

The original template JavaScript and Bootstrap JavaScript have been excluded as requested. Pages are converted to React JSX; CSS, Bootstrap styles, icons, fonts and images are retained. Components that depend on JavaScript (such as dropdowns, charts, sidebar toggles, date pickers, and interactive form behaviors) may not function.
