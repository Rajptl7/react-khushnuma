# MediCloud React + Vite (HTML/CSS/Bootstrap only)

## Run
1. Install Node.js (if not already installed).
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Important
- The original page markup has been converted to React JSX.
- The original SCSS and image assets are retained.
- Bootstrap styling is included through the original SCSS build.
- No template JavaScript, GSAP, navbar.js, main.js, or Bootstrap JavaScript is loaded.
- Therefore navbar collapse, modal, and FAQ accordion interactions that depend on JavaScript will not work. Static page layout and CSS styling remain.
